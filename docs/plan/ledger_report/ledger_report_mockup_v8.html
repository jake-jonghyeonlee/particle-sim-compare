얼마나 달라졌나

1. 전체 비교

vi 는 불량 발생 비율입니다. 양품 수율이 아닙니다. 값이 커지면 위험이 커집니다.

vi_line 은 line 불량의 발생 비율, vi_pixel 은 pixel 불량의 발생 비율입니다(보정 후). 이 보고서의 큰 글씨 % 는 A 의 전체 vi 를 100% 로 본 값입니다. line 값은 vi_line A 가, pixel 값은 vi_pixel A 가 기준입니다. 두 기준이 다르므로 line % 와 pixel % 는 서로 더하거나 비교하지 않습니다. 작은 글씨는 원래 값(%, %p)입니다.

변화 종류 — 달라진 양이 어떤 종류의 변화에서 왔나

줄을 누르면 2절 지도와 4절 장부에 그 종류만 남습니다. 오른쪽(빨강)은 증가 합, 왼쪽(파랑)은 감소 합입니다. 변화 종류는 확인된 사실만 말합니다. 형상이 실제로 어떻게 달라졌는지는 2절과 5절의 지도에서 봅니다.

3. 전극별

전극 쌍의 불량은 두 전극에 절반씩 넣습니다. CNO 는 그 전극에 전부 넣습니다. 전극 이름이 곧 기능입니다.

7. 참고

계산 규칙

% 단위A 의 전체 vi 를 100% 로 본 값입니다. line 은 vi_line A, pixel 은 vi_pixel A 가 기준입니다. A 의 전체 vi 가 0 이면 % 를 계산하지 않고 원래 값만 보입니다.
절반 분할전극 쌍의 값을 두 전극에 1/2 씩 넣습니다.
공유 영역 분담여러 쌍이 함께 덮는 영역은 덮는 쌍 수 n 으로 1/n 씩 나눕니다.
합계 관계불량 종류마다: 전극 쌍 합 + CNO = 전극 장부 합. 전극 장부 합 + CRP 차이 = 1절 전체. 1절 전체는 장부와 따로 계산한 값과 대조합니다.
A 값 · B 값전체 변화를 나눈 것과 같은 방식으로 각 제품의 값을 나눈 값입니다(근사). CRP 차이는 전극에 나누지 않고 1절에 한 줄로 둡니다.
주변 범위5절 표의 범위는 그 쌍의 불량 영역에서 10 µm 안쪽입니다. 다른 쌍은 범위 안에 든 부분만 셉니다. line 과 pixel 을 따로 셉니다.
같은 좌표 비교같은 쌍, 같은 레이어이고 A 와 B 의 위치가 대응될 때만 범위 합계를 A → B 로 비교합니다. 그 밖에는 있는 쪽의 값만 보입니다.
가장자리범위가 입력 밖으로 나가면 같은 위치의 안쪽 반복을 씁니다. 반복이 같은 패턴인지 확인된 경우에만 씁니다. 아니면 범위 밖을 빗금으로 칠하고 비교에서 뺍니다.
지도불량 영역은 5 µm 이물의 중심이 놓이면 불량이 되는 위치입니다. 값은 선택한 이물 크기 전체의 합이라 넓이와 값이 비례하지 않습니다. 색과 진하기는 쌍 전체의 값이고, 그 위치만의 값이 아닙니다.
표시"없음" 은 그 제품에 그 전극이나 쌍이 없다는 뜻입니다. "0%" 는 있지만 값이 0 이라는 뜻입니다. "해당 없음" 은 그 불량 종류와 관계가 없다는 뜻입니다.

불량 종류line 또는 pixel
